# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions on [our FAQ](https://github.com/changesets/changesets/blob/main/packages/cli/README.md#frequently-asked-questions)

## Adding Changesets

To add a new changeset, run `changeset` or `changeset add` from the repository root. This will walk you through the process of creating a changeset, which will then show up in this directory.

## Changesets VS Versions

By default, Changesets will create files in the `.changeset` folder. As this is not the idiomatic way most people manage their repo, the Changesets team created `@changesets/cli` so you can use this to publish rather than having to merge changesets to main.

However, how to use changesets is a complex topic, so we recommend reading our [detailed CONTRIBUTING guide](../../CONTRIBUTING.md) for how to use changesets with this project.
