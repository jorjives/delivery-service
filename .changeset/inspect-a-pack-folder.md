`delivery packs inspect` takes the path to a pack folder, inside a project or outside one. It names the check and landing your project's own settings would use, and lists a README or housekeeping file as not read. It refuses the whole folder, naming each path, when the folder holds a link, a script, or any other file a pack does not name, or an instruction file that no workflow uses, so a pack that cannot be fully described is never shown as if it were fine.
